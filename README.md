# タルコフ タスク・脱出ナビ

Escape from Tarkovのタスク、マップ、脱出地点、鍵の用途を日本語で素早く確認するデスクトップアプリです。ゲームプレイ中に必要な情報へ短い操作でたどり着けるよう、一覧で探して詳細を確認する構成にしています。

## 機能一覧

### タスク情報

タスク情報では、ストーリータスク、サブタスク、バトルパスを切り替えて確認できます。

- トレーダー別のタスク一覧とタスク検索
- タスク名、英語名、トレーダー名、関係するマップ名による検索
- スペースや記号を省略した検索（例：`Big Sale` と `bigsale`）
- 推奨順、レベル順、名前順の並べ替え
- マップ別、トレーダー別のグループ表示
- 特定のマップ、またはANY MAPの絞り込み

タスク詳細では、次の情報を上から順に確認できます。

- 解放条件
- 必要な鍵、レイドへ持ち込む物、入手・納品する物
- 達成手順、必要数、FIR条件、目的地点の座標
- タスク全体に関係するマップの一覧
- 目的地点を示すマップと、建物・室内・目印の参考画像
- タスク専用攻略ページへのリンク

タスクに複数の目的地点がある場合も、関係するマップはタスク全体の情報としてまとめて表示します。目的地点のマップを選ぶと、座標や対象地点を確認できます。画像はクリックして拡大表示できます。

### マップ

マップ画面では、全体図のマップ名を選んで脱出地点を確認できます。全体図に載っていないマップは、画面下の追加マップ一覧から開けます。

- PMC専用、SCAV専用、共通、他マップへのトランジットの分類
- 脱出地点名、利用条件、方角などの一覧表示
- 脱出地点を選択したときの自動フォーカスとマップ上の強調表示
- マップ上の強調箇所をクリックして開く詳細表示
- ドラッグによる移動、マウスホイールとボタンによる拡大・縮小
- 「全体表示」による表示位置のリセット

脱出地点の位置表示に対応した基準マップでは、マップ画像に印刷された名称を基準に強調表示します。位置表示に対応していない画像版へ切り替えた場合は、画像を閲覧できますが、脱出地点の強調表示は基準マップで使用してください。

### 脱出地点の詳細

脱出地点を一覧から選ぶと、マップ上の該当箇所へ移動し、選択中の脱出地点を表示します。詳細表示では、取得できた現地参考画像、Wikiの説明、画像検索へのリンクを確認できます。通信状況や掲載状況によって画像を取得できない場合は、利用可能な情報と外部リンクを表示します。

### 別マップ画像

英語版WikiのMaps節から、同じマップの別画像を確認できます。2D・3D・屋内図など、掲載されている画像の種類を切り替えて比較できます。

別画像のタイトルは、選択中のマップ名と画像の種類を組み合わせて表示します。別画像は閲覧用で、脱出地点の強調表示や位置表示を使う場合は「脱出地点対応マップ」に戻してください。

### 鍵Wiki

鍵Wikiでは、レイドで拾った鍵を保管するか判断するために、鍵の用途をまとめて確認できます。

- 鍵名、英語名、タスク名、トレーダー名、マップ名による検索
- スペースや記号を省略した検索
- 使用マップによる絞り込み
- タスクで使う鍵／タスク以外で使う鍵の絞り込み
- 鍵のカテゴリ、使用回数、関連タスク、対応マップの確認
- 「鍵を使う場所（Lock Location）」の確認
- 「開錠先で入手・利用できるもの（Behind the Lock）」の確認
- 使用場所と開錠先の日本語説明、および必要に応じた英語原文の表示
- 関連タスクからタスク情報へ移動
- Wiki掲載情報の確認と、最新データ取得

鍵を選ぶと、タスクで必要か、使用場所が登録されているか、用途を確認できない状態かを画面上部で判断できます。Wikiの該当節が見つからない鍵は、その旨を表示して外部Wikiでの確認を案内します。

### 検索・絞り込みの共通仕様

検索語は全角・半角、大文字・小文字、スペースや記号の違いを吸収して照合します。英語名をそのまま入力したり、単語間のスペースを省略したりしても検索できます。

一覧の絞り込みや並べ替えの状態は画面ごとに保存され、次回表示時に復元されます。検索結果から詳細を開いた後に一覧へ戻る場合も、直前の検索・表示位置を維持します。

### オンライン更新とオフライン利用

アプリには初期表示用のタスク、マップ、鍵データを同梱しています。通信できる場合は、画面の更新操作や起動時の確認によって最新データを取得します。取得に失敗した場合は、同梱データまたは保存済みデータを利用します。

マップ画面の「このマップをオフライン保存」から、表示中のマップ画像を保存できます。保存後は通信できない環境でも保存済み画像を表示できます。別マップ画像は画像ごとに保存が必要です。

## 必要環境

- Node.js 22.13.0以上
- npm
- Windows版の配布物を作成する場合はWindows環境

## Windows配布版の使い方

配布フォルダを任意の場所へ展開し、その中の `win-unpacked/` フォルダにあるアプリ実行ファイルを起動してください。インストール作業は必要ありません。

配布版では、タスク・マップ・鍵Wikiの基本機能を利用できます。外部Wikiの画像、オンライン更新、未保存のマップ画像にはインターネット接続が必要です。事前にマップ画像を保存しておくと、保存済み画像をオフラインで確認できます。

## 開発版の起動

```bash
npm install
npm run dev
```

Windowsでは起動用バッチファイルからも開発版を起動できます。

## デスクトップ版のビルド

```bash
npm run desktop:build
```

生成物は `package.json` の `build.directories.output` で指定したフォルダに出力されます。

- `win-unpacked/`: 確認・配布用の展開済みポータブル版

現在はインストーラーやZIPを生成せず、`win-unpacked/` のみを配布対象とします。

## データと保存先

- タスクの初期データは `app/data/` に収録しています。
- タスクやマップで使用する静的画像は `public/` に収録しています。
- 一部のタスク、Wiki画像、翻訳、別マップ画像、鍵情報はインターネット接続時に外部サービスから取得します。
- 鍵カタログの同梱データは `npm run keys:update` で更新できます。

## ディレクトリ構成

```text
app/       React画面、スタイル、タスクデータ
desktop/   Electron向けViteエントリーポイント
electron/  ElectronメインプロセスとIPCブリッジ
public/    タスク、マップ、トレーダー用画像
worker/    Vinext／Cloudflare Workerエントリーポイント
db/        将来用のDrizzle設定
tests/     テストコード
```
