# タルコフ タスク・脱出ナビ v1.1.0-test.30

マップ選択画面の表示不具合を修正したテスト版です。

## 修正内容

- 全体マップ上の選択枠が不透明になり、枠内のマップ名を隠していた問題を修正しました。
- 共通UIスタイルの対象から、背景画像上に置く透明なマップ選択枠を除外しました。
- 選択枠の位置・クリック範囲・ホバー表示は維持しています。
- Web版とElectron配布版の両方で同じ修正が適用されます。
- 同種のCSS競合を検出する回帰テストを追加しました。

## 配布物

`win-unpacked/` の内容を `Tarkov-Task-Extract-Navi-test-v30` フォルダ直下へ配置し、その版名フォルダをZIP化して配布します。インストーラーは含みません。ZIPを展開し、版名フォルダ内の `タルコフ タスク・脱出ナビ.exe` を実行してください。
