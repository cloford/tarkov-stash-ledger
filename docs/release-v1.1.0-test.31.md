# タルコフ タスク・脱出ナビ v1.1.0-test.31

操作や表示内容を変えず、アプリの初期表示・マップ表示・画面遷移を軽量化したテスト版です。

## 更新内容

- MAP・鍵Wikiは開くまで読み込まないようにし、タスク情報をすばやく開けるようにしました。
- 保存済みの高解像度マップ画像をIPCで複製せず、安全な専用URLから表示するようにしました。
- タスク詳細で使う翻訳・必要条件・武器ビルド情報を短時間共有し、同じ情報の再取得を抑えました。
- 画面外の鍵画像、タスク画像、現地参考画像、武器パーツ画像を遅延読み込みにしました。
- すぐに必要な全体マップ、詳細画像、拡大画像は従来どおり優先して表示します。

## 配布物

`win-unpacked/` の内容を `Tarkov-Task-Extract-Navi-test-v31` フォルダ直下へ配置し、その版名フォルダをZIP化して配布します。インストーラーは含みません。ZIPを展開し、版名フォルダ内の `タルコフ タスク・脱出ナビ.exe` を実行してください。
