# タルコフ タスク・脱出ナビ v1.1.0-test.32

マップ・タスク・初期表示の軽量化を反映したテスト版です。

## 更新内容

- 起動中のタスク・マップ・鍵データ更新を共有し、同じ情報の重複取得を抑えました。
- タスク検索用の情報を再利用し、検索・並べ替え・詳細表示時の計算と再描画を軽量化しました。
- 高解像度マップの別画像取得と保存済み画像の確認を共有し、不要な通信と再計算を抑えました。
- マップの注釈、鍵位置、ドラッグ、ズームの表示に必要な値を再利用し、操作中の負荷を軽減しました。
- 既存の操作方法、マップ表示、タスク・鍵Wikiの情報は維持しています。

## 配布物

`win-unpacked/` の内容を `Tarkov-Task-Extract-Navi-test-v32` フォルダ直下へ配置し、その版名フォルダをZIP化して配布します。インストーラーは含みません。ZIPを展開し、版名フォルダ内の `タルコフ タスク・脱出ナビ.exe` を実行してください。
