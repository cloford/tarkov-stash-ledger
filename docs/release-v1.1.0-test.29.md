# タルコフ タスク・脱出ナビ v1.1.0-test.29

ゲーム前・ゲーム中に必要な情報を短時間で確認できるよう、画面の情報設計とマップ一覧を整理したテスト版です。

## 今回の更新

### 画面を見やすく整理

- アプリ画面上の大きな「TARKOV NAVI」表示を削除し、タブと本文をすぐ確認できる構成にしました。ウィンドウのタイトルは従来どおりです。
- 文字サイズ、余白、パネル、選択状態、ボタンの見た目を統一しました。選択中の項目は色・枠・アクセントで判別できます。
- 狭い画面幅でも横にはみ出しにくいレイアウトへ調整しました。

### タスク情報を短く、探しやすく

- 各ステップに繰り返し表示されていたマップ名とWikiリンクを削除しました。
- タスクに関係するマップは詳細の上部に一度だけ表示します。
- 完了報酬と経験値報酬の表示を削除し、目的・準備・場所を優先して確認できるようにしました。

### マップの重複表示を修正

- Factory／Night Factory、Ground Zeroの派生、The Labの派生など、同じ実地マップを指すデータを基準マップへ正規化しました。
- マップ選択、タスクの絞り込み、関連マップへの移動で同一マップが重複表示されないようにしました。

## 使い方

### タスク情報

1. 上部の「タスク情報」を開きます。
2. 検索欄にタスク名を入力します。英語名は空白を省略しても検索できます。
3. 一覧からタスクを選ぶと、目的、必要な鍵、関連マップ、参考画像を確認できます。
4. 関連マップのボタンから、対象マップへ直接移動できます。

### マップと脱出地点

1. 上部の「マップ」を開き、マップを選びます。
2. 右側の脱出地点を選ぶと、該当する地点へ自動で移動して強調表示します。
3. マウスホイールで拡大・縮小し、ドラッグでマップを移動できます。
4. 別バージョンのマップを選んだ場合は、画像の比較用として表示します。脱出地点の強調表示は対応する基本マップで利用してください。

### 鍵Wiki

1. 上部の「鍵Wiki」を開きます。
2. 鍵名、タスク名、マップ名で検索します。空白を省略した検索にも対応しています。
3. 鍵を選ぶと、使用場所、関連タスク、開錠先で入手・利用できるものを確認できます。
4. 関連マップや関連タスクのボタンから、それぞれの画面へ移動できます。

## 配布物

`win-unpacked/` の内容を `Tarkov-Task-Extract-Navi-test-v29` フォルダ直下へ配置し、その版名フォルダをZIP化して配布します。インストーラーは作成しません。ZIPを展開し、版名フォルダ内の `タルコフ タスク・脱出ナビ.exe` を実行してください。

## テスト版について

この版は `v1.1.0-test.29` です。ゲームや外部Wikiの更新により、タスク条件・画像・脱出地点情報が変わる場合があります。
